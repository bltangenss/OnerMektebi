# Өнер мектебі — сайт творческой школы, Туркестан

Сайт небольшой школы искусств: күй, айтыс и рисование. На двух языках: казахский (основной) и русский. Подходит для телефона, сделан на Next.js.

Концепция «Өнерге бастар алғашқы қадам». Визуальный язык взят из сырмақа: узор из пары рогов (қошқар мүйіз) вырезан из двух войлоков и поменян цветами, поля разделены пунктирным швом. На первом экране лежит домбра, и её струны откликаются на касание (без звука).

## Что есть на сайте

- **Главная**: первый экран с домброй, о школе, направления, «Өнерді таны» (выбор искусства), галерея, «Өнердің үні» (аудио), события, педагоги, призыв связаться.
- **Мектеп туралы**: миссия, атмосфера, педагоги, история и достижения (показываются только подтверждённые).
- **Өнер бағыттары** и универсальная страница направления `/kk/directions/<slug>` с тремя оформлениями: струны (кюй), два голоса (айтыс), мазок кисти (рисование), плюс обычное для новых направлений.
- **Жас таланттар**: галерея с фильтрами, просмотр рисунков, видео и аудио, режим «Цифровая выставка».
- **Мектеп өмірі**: предстоящие и прошедшие события, «Өнер күнтізбесі», страница события с постоянной ссылкой (её можно поместить в QR-код на афише).
- **Байланыс**: контакты, WhatsApp с выбором направления, карта.
- **Өтінім қалдыру** `/kk/apply`: заявка на запись или вопрос. Ссылка `/kk/apply?type=enroll&direction=kui` сразу выбирает направление.
- **События**: кнопки «Добавить в календарь» (файл .ics), «Поделиться в WhatsApp» и печатная афиша A4 с QR-кодом (`/kk/events/<slug>/poster`).
- **/admin**: админ-панель на Supabase: заявки со статусами, события, работы, направления, педагоги, достижения, история, контакты.

Чего на сайте нет и не будет: дневников, оценок, личных кабинетов, оплаты, публичной загрузки файлов.

## Онлайн-заявки

Форма заявки работает только при подключённом Supabase. Без него страница `/apply` предлагает связаться напрямую, и форма, которая ничего не сохраняет, не показывается.

- Поля: имя взрослого, телефон, удобный способ связи, направление, возраст ребёнка (необязательно), сообщение, согласие на обработку данных. Имя ребёнка не собирается.
- «Заявка принята» показывается только после того, как база подтвердила запись. При ошибке введённые данные остаются в форме.
- Защита от спама: скрытое поле-ловушка, минимальное время заполнения, не больше 3 заявок с одного адреса за 15 минут и 30 в час со всего сайта (проверяется в самой базе). IP хранится только в виде хеша.
- Читать заявки могут только администраторы (RLS). Добавить заявку можно лишь через функцию `submit_application`.
- В админке у заявки есть статусы «Новая / В работе / Закрыта», ответ в WhatsApp на языке заявки, звонок одним нажатием, заметки и удаление. Закрытые заявки с личными данными лучше удалять, когда они больше не нужны.
- Уведомление в Telegram подключается по желанию (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`). В нём нет имени и телефона, только тип заявки и ссылка на админку.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:3000, сайт перенаправит на `/kk`.

Режим с демо-материалами (помечены «Үлгі / Образец»; рисунки нарисованы для проекта, мелодия и видео синтезированы):

```bash
npm run dev:demo
```

Проверки и сборка:

```bash
npm run typecheck
```

```bash
npm run lint
```

```bash
npm run build
```

## Подключение админ-панели (Supabase)

1. Создайте проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните целиком `supabase/schema.sql`. Он создаёт таблицы, политики доступа, хранилище `media` и три стартовых направления.
3. В **Authentication → Sign In / Providers** отключите самостоятельную регистрацию (Allow new users to sign up).
4. В **Authentication → Users** создайте пользователя для сотрудника (email и пароль).
5. Сделайте его администратором в SQL Editor:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'staff@example.com';
   ```
6. Укажите переменные из `.env.example` (локально в `.env.local`, на хостинге — в настройках проекта).
7. Войдите на `/admin/login`.

Как устроена защита:

- Публичные страницы читают данные публичным ключом. Политики RLS отдают только опубликованное, а работы детей — только при отмеченном согласии родителей. Это правило продублировано ограничением в самой таблице.
- Каждое действие админки на сервере проверяет, что пользователь вошёл и записан в `admins`. Proxy (`src/proxy.ts`) не пускает в `/admin` без входа.
- Файлы загружаются из браузера сотрудника прямо в Supabase Storage. Писать в хранилище могут только администраторы; размер (до 50 МБ) и типы файлов ограничивает сам бакет. Сервер принимает только ссылки на собственное хранилище.
- Перед удалением запрашивается подтверждение, файлы записи удаляются вместе с ней.

> Админ-панель собрана и проверена на типы и сборку, но **не проверялась на живом проекте Supabase**: в среде разработки его не было. Перед передачей сотрудникам пройдите шаги выше и проверьте создание, публикацию и удаление записи.

## Публикация (Vercel)

1. Импортируйте репозиторий на [vercel.com](https://vercel.com).
2. Укажите переменные окружения: `NEXT_PUBLIC_SITE_URL`, при необходимости переменные Supabase. `NEXT_PUBLIC_DEMO_CONTENT` должна быть `false`.
3. Deploy. Подключите домен в настройках проекта.

Подойдёт и любой хостинг с Node.js: `npm run build`, затем `npm start`.

## SEO и превью ссылок

Для каждой страницы заданы свои title и description на двух языках, canonical, hreflang (kk, ru, x-default) и Open Graph. Картинка-превью генерируется на лету с правильными казахскими буквами. Есть `sitemap.xml` и `robots.txt` (админка закрыта от индексации), разметка Schema.org School на главной (только название, город и заполненные контакты) и Event на страницах событий.

## Структура

```
src/
  app/[locale]/        публичные страницы (kk, ru)
  app/admin/           админ-панель
  components/art/      домбра, струны, орнамент, логотип
  components/…         разделы страниц
  content/             контент без CMS и демо-материалы
  lib/                 локализация, контент, даты, WhatsApp, SEO, Supabase
  locales/             словари kk и ru
  types/               типы данных
supabase/schema.sql    схема CMS
```

## Доступность и анимации

Семантическая разметка, переход к основному содержанию, видимый фокус, клавиатурное управление галереей (стрелки, Escape), доступное мобильное меню с удержанием фокуса. Анимации сдержанные и отключаются при `prefers-reduced-motion`. Автовоспроизведения звука нет.

Список данных, которые нужно получить от школы: [CONTENT_CHECKLIST.md](CONTENT_CHECKLIST.md).
