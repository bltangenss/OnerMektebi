# Что нужно получить от школы перед запуском

Сайт ничего не выдумывает: всё, чего нет в этом списке, на нём не показывается или заменено честной заглушкой. Ниже — что собрать у администрации, чтобы сайт заработал в полную силу.

## Обязательно до запуска

- [ ] **Адрес школы** на казахском и русском.
- [ ] **Телефон** для звонков (как его должны видеть посетители).
- [ ] **Номер WhatsApp** в международном формате (77XXXXXXXXX). Без него на сайте нет кнопок WhatsApp: ведут на страницу контактов.
- [ ] **Ссылка на карту**: точка школы в 2ГИС или Google Maps, а также ссылка «Встроить карту».
- [ ] **Instagram** и другие официальные страницы, если есть.
- [ ] **Время работы**, если школа хочет его публиковать.
- [ ] **Логотип**, если есть официальный. Сейчас стоит временный знак: `src/components/art/Logo.tsx` и `public/icon.svg`.
- [ ] **Домен** и где будет размещён сайт.

## Педагоги

Для каждого — только с его согласия:

- [ ] ФИО на казахском и русском.
- [ ] Направление или должность.
- [ ] Фотография (вертикальная, хорошего качества).
- [ ] Короткий подтверждённый опыт, по желанию.
- [ ] Какие направления ведёт (связь с карточкой направления).

## Направления

- [ ] Проверить тексты о кюе, айтысе и рисовании (`src/content/directions.ts` или админ-панель). Они написаны в общих словах о самом искусстве, без фактов о школе.
- [ ] Возраст детей, расписание, стоимость и порядок записи — **только если школа хочет их публиковать**. Сейчас сайт предлагает уточнить это у администрации.
- [ ] Фотографии занятий для каждого направления. Пока их нет, показываются авторские иллюстрации-орнаменты.
- [ ] Другие направления, если они есть.

## Работы учеников («Жас таланттар»)

- [ ] **Письменное согласие родителей или законных представителей** на каждую публикуемую работу. Без отметки о согласии админ-панель не даст опубликовать работу.
- [ ] Отдельное согласие, если рядом с работой нужно указать имя ребёнка. По умолчанию работы анонимны.
- [ ] Рисунки: сканы или фото при хорошем свете, без лиц детей, если на это нет согласия.
- [ ] Записи кюев (аудио) и видео выступлений, право на которые есть у школы.

## Мероприятия

- [ ] Ближайшие концерты, выставки и конкурсы: название, дата, время, место, описание, афиша.
- [ ] Фотографии прошедших мероприятий (с согласием на съёмку детей).

## О школе

- [ ] Подтверждённая история: год основания и важные даты. Без них временная шкала не показывается.
- [ ] Настоящие награды, дипломы и выступления. Без них раздел «Достижения» показывает только пояснение.
- [ ] Фотографии атмосферы школы: здание, классы, занятия.

## Перед публикацией

- [ ] Выключить демо-режим: `NEXT_PUBLIC_DEMO_CONTENT=false`.
- [ ] Указать `NEXT_PUBLIC_SITE_URL` с реальным доменом.
- [ ] Если нужна админ-панель: создать проект Supabase, выполнить `supabase/schema.sql`, создать учётные записи сотрудников (см. README).
- [ ] Носителю языка вычитать тексты на казахском и русском.
